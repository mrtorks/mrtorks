I'm a software development manager who's been building for the web for over seven years, mostly full stack, and I still write a good share of the code myself.

These days that means Laravel, Livewire, Alpine and Tailwind on a large app that's been around a while. I've also spent a lot of time with Ruby on Rails and Node, and I've worked with Go, C++ and Scala.

### Things I care about

- Interfaces that are fast and don't need explaining
- Cleaning up legacy code a piece at a time instead of waiting for a rewrite
- Security that's paranoid but practical

Lately I've been spending time on design systems and AI tooling.
